감과 달랐던 것 ①

메모리 예산. "노드 6GB + 모델 4~5GB" 로 적었는데 모델 서버는 안정 7.9GB, 첫 시작 땐 12GB 를 넘겼다. 호스트 Docker 에선 상한이 없어 그 비용이 보이지 않았다.

감과 달랐던 것 ②

무상태는 저절로 되지 않는다. Pod 를 셋으로 늘리고 로드 밸런서가 골고루 나눠 줘도, 승인 대기가 Pod 안 SQLite 에 있으면 늘린 게 아니다(409). DB 로 옮기자 200.

감과 달랐던 것 ③

측정기부터 의심. 30회 중 3회가 빠진 건 요청이 아니라 kubectl run -i 가 앞 줄을 잃은 것(D45). 코드를 찍게 고치고, logs 로 읽게 고치자 30/30.
