★ 꼭 구분하세요

bge-m3 는 답을 쓰는 AI 가 아닙니다.

글을 숫자로 바꿔 찾기만 합니다.답은 Qwen3 가 씁니다.둘은 역할이 달라 하나를 키운다고 다른 쪽이 좋아지지 않습니다— 그래서 따로 잽니다(검색은 R@3, 에이전트는 과업 성공).

★ 하나 더

SGLang 은 모델이 아닙니다.

Qwen3 를 GPU 에 올려 돌리는 실행 도구입니다.엔진을 vLLM 으로 바꿔도 모델은 같고 답도 같아야 하며,다른 건 속도(첫 글자 시간 · 처리량)뿐— 3주차가 그걸 쟀습니다.

외울 것은 하나입니다 — 「무엇으로 찾는가」 「무엇으로 쓰는가」 「무엇으로 조립하는가」는 서로 다른 질문이고, 셋을 «각각» 재서 고르는 것입니다 이 저장소의 「지금 기본값」 표(README)가 그 세 답입니다: 찾기 = 라우팅(BM25 · bge-m3), 쓰기 = SGLang + Qwen3-4B(FP8) 생각 모드, 조립 = LangGraph + MCP + 안전 기능 여섯 + 보호 기능 셋
