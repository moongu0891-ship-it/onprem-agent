에이전트 안쪽 — 질문 하나가 답이 되기까지 일곱 걸음

그림 1 의 「에이전트 그래프」 상자 하나를 열어 본 것입니다. 상담 화면의 「AI가 처리한 순서」 칸이 바로 이 걸음들입니다

에이전트가 무엇인가요?

AI 에게 그냥 물으면 회사 매뉴얼을 모르니 그럴듯하게 지어냅니다(환각). 그래서 찾아보고 → 필요하면 사람에게 묻고 → 그것만 보고 답하게 하는 절차를 코드로 둡니다. 그 절차가 그래프입니다.

그래서 이렇게 합니다

① 질문에 맞는 업무 기능(도구)을 모델이 고르고
② 코드가 실행해 자료를 [절 번호] 와 함께 돌려주고
④ 기록이 남는 일은 사람이 승인해야 실행되고
⑥ 답에는 실제로 찾아본 번호만 붙습니다

→ 지어내지 않고, 어느 매뉴얼 몇 절에서 왔는지까지 댈 수 있습니다

1질문 이해 — 모델이 다음 할 일을 고름 정하는 사람

모델은 「어느 업무 기능을 어떤 인자로 부를지」만 냅니다. 찾아보지 않고 답하려 하면 검색 되돌림이 "먼저 찾아보라"는 쪽으로 돌립니다(글로 부탁하지 않고 선택지를 좁힘). 글자로 써 버린 호출은 글 호출 살리기가 진짜 호출로 바꿉니다

graph.py · agent 노드 · tool_choice

호출 (이름 + 인자)

2업무 기능(도구) 실행 — 창구 서버 찾는 사람

search_manual · get_work_orders · get_employee … 결과는 [OPS-SAFE] 같은 절 번호를 달고 돌아옵니다. 자료 속에 숨은 「AI 는 ~하라」 문장은 지시문 제거가 지웁니다

tools 노드 · MCP

자료가 모자라면 ① 로 되돌아감 (최대 6걸음)

3담당자 확인 — 기록이 남는 일은 멈춤 사람

작업 요청 등록 · 잠금 해제 요청처럼 회사 시스템에 기록을 남기는 업무 기능(approval_tools)은 그래프가 interrupt 로 멈추고 승인 카드를 띄웁니다. 승인하면 그 자리에서 이어서 실행, 취소하면 실행 안 함. 멈춘 자리는 체크포인터(SQLite / PostgreSQL)에 남아 화면을 닫았다 열어도 이어집니다

gate 노드 · Command(resume=…)

찾은 자료만 보고

4답 쓰기 — 모델 글 쓰는 사람

받은 자료만 근거로 한국어 답을 씁니다(생각 모드 켬 — 4주차 측정 54% → 92%). 생각이 길어 답이 비면 빈 답 다시 쓰기. 실행하지 않은 일을 "했다"고 쓰면 말로만 실행 막기가 「요청 기능 / 실행 안 함」 둘 중 하나를 고르게 합니다

답변
답 + 근거 번호 → 상담 화면

LangGraph 로 그리면 마디 넷

START → agent ─┬→ gate → tools → agent …
                 └→ finalize → END

agent = ①④ (모델에게 묻기), gate = ③ (승인이 필요한가), tools = ② (창구 서버 실행), finalize = ⑤⑥. 되돌아가는 화살표가 있어서 「조립 도구」로 LangChain 이 아니라 LangGraph 를 씁니다 (그림 5)

★ 꼭 구분하세요

모델은 실행하지 않습니다.

모델은 「무엇을 부를지」와 「답 글」만 냅니다. 찾기 · 등록 · 승인 · 출처 · 가리기는 전부 코드가 합니다. 그래서 모델이 "티켓을 만들었습니다"라고 써도 코드가 만든 적이 없으면 거짓 보고로 잡힙니다(그림 4)

왜 ①과 ④를 나눴나

같은 모델을 두 번 부릅니다. ①은 선택(업무 기능 이름 하나)이라 틀 안에서만 답할 수 있게 API 로 강제할 수 있고, ④는 글이라 자유롭습니다. 6주차에 "강제를 글에까지 걸었더니 바른 거절을 버리고 엉뚱한 호출로 바꾸더라"를 재 보고 ①에만 걸었습니다(85% → 90%)

이 걸음들이 화면에 그대로

상담 화면의 「AI가 처리한 순서」 — 위험 작업 확인 · 질문 이해 · (업무 기능 이름) · 담당자 확인 · 출처 붙이기 · 개인정보 가리기 — 는 이 그림의 ⓪~⑥ 이고, 되돌림이 생기면 「다시 찾아보기」 칸이 더 생깁니다

일곱 걸음을 한 줄로 — 위험 확인 → 고르고 → 찾고 → 사람에게 묻고 → 쓰고 → 출처 붙이고 가린다 모델이 하는 건 「고르고」와 「쓰고」 둘뿐입니다. 나머지 다섯은 코드이고, 그래서 잴 수 있고 고칠 수 있습니다 — 안전 기능 하나하나가 어디에 붙어 있는지는 그림 4
